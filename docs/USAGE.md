# Usage Guide

## Home Tab

The Home tab provides an overview of your mod environment, including the detected game installation path and quick action buttons.

## Photo Mods Tab

Browse and install photo mods. Select a mod from the list to view details and click **Install** to add it to your game.

## Photo Pack ZIP Tab

Import photo packs from `.zip` files:

1. Click **Import ZIP**.
2. Select your `.zip` archive.
3. The tool extracts and validates the pack automatically.
4. Installed packs appear in the list below.

## Mod Manager Tab

Manage all installed mods:

| Action       | Description                                      |
|--------------|--------------------------------------------------|
| **Install**  | Add a new mod to the game directory              |
| **Uninstall**| Remove a mod and restore the original file        |
| **Enable**   | Activate a disabled mod                          |
| **Disable**  | Temporarily disable a mod without removing it    |

## Game Status Tab

View real-time information about the game:

- Installation path
- Game version
- Whether the game process is currently running

## Settings Tab

Configure the application:

- **Default Directory** — Set the base path for mods and photo packs.
- **Theme** — Switch between dark and light themes.
- **Backup Interval** — Set how often automatic backups are created.
- **Language** — Change the UI language (English / Turkish).
