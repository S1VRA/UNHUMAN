# Security Policy

## Supported Versions

| Version | Supported          |
|---------|--------------------|
| 0.4.x   | ✅ Yes             |
| < 0.4   | ❌ No              |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly.

**Do not** open a public GitHub issue for security vulnerabilities.

### Preferred Method: GitHub Private Security Advisory

1. Go to [Security Advisories](https://github.com/S1VRA/UNHUMAN/security/advisories/new)
2. Click "Report a vulnerability"
3. Fill in the details privately

The maintainers will be notified privately and will respond within **7 days**.

### What to Include

- A clear description of the vulnerability
- Steps to reproduce
- Potential impact
- Affected version(s)
- Suggested fix (if applicable)

### Our Commitment

- We will acknowledge receipt within **72 hours**
- We will provide a timeline for a fix
- We will credit you in the release notes (unless you prefer to remain anonymous)

Thank you for helping keep NH Mod Tool secure.
